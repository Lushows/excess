# EXCESS · la cabina

Sitio de EXCESS, DJ de hardtechno de la sabana de Bogotá. La página es un reproductor de club:
BROWSE (sus sets de SoundCloud), HISTORY (dónde ha tocado), CUE LIST (próximos toques), INFO y LINK (booking).

- Próximos toques: editar `datos/fechas.json` (las fechas con `"ejemplo": true` se borran antes del lanzamiento).
- Lugares donde ha tocado: `datos/historial.json`.
- Versión de prueba: lleva `noindex` para que no aparezca en Google hasta el lanzamiento.
